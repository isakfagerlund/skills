# Cursor theme

Calm and light: warm off-white paper, a muted four-colour palette, flat tiles with the grid showing between them. The default theme.

## Canvas and type

- Canvas background `#f1f0ec`, warm off-white, with 32px padding and `border-radius: var(--radius, 12px)`.
- Text `#393a38`, dark charcoal. Secondary text `#736f65`.
- Sans-serif text: `var(--font-sans, ui-sans-serif, system-ui, sans-serif)`.

## Palette

Muted illustration colours:

- blue `#6b8cae`
- forest green `#3f6b4a`
- mustard yellow `#d4a53c`
- warm grey `#b5aea2`

Use a lighter or darker step of the same hue for a second tone. Keep to these four families plus brand colours. Give each customer or account its own family.

## Tiles

- Tile size 8 with a gap of 1: each rect is 7×7 at multiples of 8, so the grid stays visible.
- Sprites 8 to 16 tiles across.
- Flat colour only. Elements sit directly on the background, with no cards, borders around groups, shadows, gradients, textures or patterned backgrounds.

## Nav

Warm grey arrows that darken on hover. Dots in warm grey, mustard for the current page.
